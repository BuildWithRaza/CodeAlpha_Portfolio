 # 🚀 Project- Personal Portfolio Website

This project was built using HTML, CSS, and JavaScript to create a modern, responsive, and user-friendly portfolio that showcases my skills, projects, resume, and contact information
.
 
### [🌐Live Demo](https://buildwithraza.github.io/CodeAlpha_Portfolio/)

## 🔥 Features

- Responsive design for desktop, tablet, and mobile.
- Smooth scrolling navigation.
- Interactive animations and hover effects.
- Dedicated sections for About, Skills, Projects, and Contact.
- Clean and user-friendly UI.

## 🛠️ Technologies

- HTML
- CSS
- Java Script
